Висновок:

Життєвий цикл об'єкта в C# охоплює три основні етапи:
1. Створення та ініціалізація: Об'єкт створюється у динамічній пам'яті (Heap) за допомогою оператора new. Конструктори класу ініціалізують його початковий стан, а властивості забезпечують валідацію даних.
2. Активне використання: Об'єкт виконує свої функції через виклики методів (StartEngine), поки на нього існує принаймні одне активне посилання.
3. Завершення та знищення: Коли посилання обнуляються (null), збірник сміття (Garbage Collector) під час очищення пам'яті викликає деструктор (~Car) та вилучає об'єкт із пам'яті.
